# Haritha Kongi — Diploma Portfolio

A clean, responsive portfolio showcasing diploma education, technical skills, and projects.

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

## Portfolio sections

- Introduction and profile
- Technical skills
- Diploma projects and experiments, with their available live demos and source links
- Education
- Social and contact links

Project records are maintained in `src/data/portfolio.js`. Existing project demo pages are kept under `projects/` and `public/projects/`.
